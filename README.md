# promptchan-proxy-relay

## Dead Signal (browser game)

`game/index.html` is a self-contained Three.js survival shooter (Fallout-style HUD, DayZ-style survival). It is served at `/game/` on the Netlify deploy, or open the file directly in a browser.

Scavenge three radio parts from the ruins, repair the beacon at the map center, and survive until extraction. Manage health, stamina, food, water and radiation; ferals hunt by sound, raiders shoot on sight.
